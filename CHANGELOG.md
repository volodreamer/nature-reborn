# Changelog

## 0.1.0-alpha

- Biome-based grass, flowers, saplings, and tree death/spread
- Forest density rules, 2x2 jungle/dark oak, rare fallen logs, leafless trunk cleanup
- Crops: spread (fences block it), farmland conversion, senescence, auto-replant; ±1 height on slopes
- Village damping so streets and buildings are not overgrown
- Extended fire (optional burn-until-consumed)
- Lumberjack **experimental**, off by default (Mod Menu → Trees)
- Cactus, sugar cane, mushrooms, lily pads, and dead bushes
- Cobble / stone bricks weather to mossy next to water, rain, or moss
- Tag `v*` on GitHub builds a release jar (26.3 only)
- Server-side simulation; Cloth Config + Mod Menu
